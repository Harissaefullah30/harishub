# HarisHub

## Deskripsi
Aplikasi pribadi untuk menyimpan & mengelola hal-hal penting:
akun, password, catatan, materi kuliah, link, dokumen, dan lainnya.

## Pemilik
Haris Rizki Saefullah

## Tagline
"HarisHub: semua di sini."

## Visi
Satu tempat untuk semua hal penting, rapi, aman, dan mudah diakses.

## Prinsip
- Multi-user (semua user sama, tanpa admin)
- Pendaftaran terbuka
- Data terpisah total per user
- Password dienkripsi
- Backup otomatis + manual
- Catatan & Materi Kuliah dipisah
- Dikerjakan bertahap per halaman
