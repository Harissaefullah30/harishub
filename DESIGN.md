# Panduan Desain HarisHub

## Identitas Visual
- **Inisial:** HS
- **Kesan:** Formal, modern, rapi, terpercaya

## Warna
- Primer: Biru tua (`#1E3A5F`)
- Sekunder: Biru medium (`#2E5A8A`)
- Aksen: Biru muda (`#4A90D9`)
- Background: Putih (`#FFFFFF`) / Abu sangat muda (`#F5F7FA`)
- Teks utama: Hitam (`#1A1A1A`)

## Tipografi
- **Font:** Inter (via Google Fonts)

## Elemen Visual Modern
- **Ikon:** Lucide React (garis tipis, hyper-minimal)
- **Gaya:** Bento Grid (kotak kartu rounded 8-12px, shadow halus)
- **Interaksi:** Hover halus, transisi cepat (150-200ms)
- **Yang dihindari:** Emoji, font jadul, gradient norak, animasi berlebihan.
