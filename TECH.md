# Teknologi & Arsitektur HarisHub

## Stack
- **Frontend & Backend:** Next.js + React + TypeScript (App Router)
- **Styling:** Tailwind CSS
- **Ikon:** Lucide React
- **Database & Auth:** Supabase (PostgreSQL)
- **Deploy:** Vercel

## Struktur Folder Utama
- `src/app/` : Halaman (routing)
- `src/components/` : Komponen UI reusable
- `src/lib/` : Utilitas & koneksi database
- `src/modules/` : Logika per fitur (akun, catatan, dll)
